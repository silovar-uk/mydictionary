# 私辞典

気になった言葉・文章・概念を、出会った場面ごと拾い、育て、忘れたころにまた開くためのローカルファースト辞書アプリ。

## できること

- 見出し語だけで5秒登録
- 意味、出典、出会った場面、使い方、タグを後から追記
- 見出し語以外も含む全文検索
- 辞書を適当に開くようなセレンディピティ表示
- 未閲覧・久しぶり・育て途中・完全ランダムの切り替え
- JSON完全バックアップ／復元
- CSV・TXTのインポート／エクスポート
- IndexedDBによる端末内保存
- 任意で有効化できる暗号化端末間同期（Quick LinksのCloudflare Workerを共用）
- PWA・オフライン利用

## 技術構成

- React + TypeScript + Vite
- IndexedDB + Dexie
- MiniSearch
- vite-plugin-pwa
- Vitest
- GitHub Pages

## 端末間同期

1. 普段使っている端末で「データ」→「端末間同期」→「同期をはじめる」。
2. 「別の端末を追加」から連携リンクをコピーし、自分のスマホ／PCで開く。
3. 新しい端末で「この端末を連携する」を押す。既存データは消さずに統合する。
4. 保存すると自動で同期。起動時・再表示時・オンライン復帰時にも確認する。

同期は任意。使わない場合は従来どおり端末内にのみ保存する。オフラインでも保存でき、再接続後に反映を試みる。「同期済み」は最終同期時の状態であり、別端末への即時配信を保証する意味ではない。

- 暗号化：ブラウザー内でAES-256-GCM。暗号鍵と認証鍵は別々に導出する。
- 保管：Quick Linksと同じWorker/R2。ただし辞典固有のランダムな保管IDと秘密鍵を使うため、両アプリのデータは混ざらない。
- 安全策：条件付き書き込み、3-way merge、完全削除の記録、競合時の選択UI。
- 上限：暗号化後のリクエスト本文は5MiB。大きな辞典は同期できない場合がある。
- 連携リンクは**秘密鍵そのもの**を含む。自分の端末だけに渡し、公開しない。受信後はURLから削除する。
- 連携解除はその端末の設定だけを削除する。端末内・共有先・ほかの端末の辞典は削除しない。
- JSONの完全復元は、誤って共有側を上書きしないよう連携を解除した状態で実行する。
- 同期はバックアップの代わりではない。JSON書き出しは引き続き推奨。

詳細：docs/SYNC_DESIGN.md

## データについて

登録内容は既定で外部送信しない。ブラウザー内のIndexedDBに保存する。ただし端末故障やブラウザーデータ削除に備え、JSON完全バックアップを定期的に書き出すこと。

詳細：[`docs/DATA_FORMAT.md`](docs/DATA_FORMAT.md)

## 公開

`main`ブランチへマージするとGitHub Actionsがビルドし、GitHub Pagesへ公開する。リポジトリ設定の Pages > Source は **GitHub Actions** を選択する。
